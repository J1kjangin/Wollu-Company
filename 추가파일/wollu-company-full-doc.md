# 월루타운 (WoLLu Company) 완전 정리

실제 게임 코드(index.html)에서 직접 추출한 데이터를 기준으로 작성했습니다. 넘버링된 목차 순서대로 게임의 처음부터 끝까지 전부 담았습니다.

---

## 1. 게임 소개 & 목표

**"회사에서 몰래 농땡이(월루)를 부리며 승진하고 돈을 버는" 아이소메트릭 방치형(idle) 오피스 타이쿤 게임**입니다.

- 출근만 해도 재화가 자동으로 쌓이고, 이를 이용해 아이템을 사고 사무실을 꾸미며 승진해나갑니다
- 최종 목표: 인턴에서 시작해 **사장**까지 승진하고, 사무실을 최고급 아이템으로 채워 생산 보너스를 극대화하는 것
- 단일 HTML 파일로 동작하며(서버 불필요), 진행 상황은 브라우저 `localStorage`에 저장됩니다

## 2. 핵심 재화 (2종)

| 재화 | 설명 |
|---|---|
| **SL (Salary Lupin)** | 아이템 구매·승진에 실제로 **소모되는** 재화. 출근 후 초당 자동 생산되며, 누적 보너스(%)에 비례해 생산량이 늘어남 |
| **TL (Time Lupin)** | 출근 후 초당 1씩 적립. 승진에 필요하지만 **소모되지 않고 계속 누적**됨 (TL 환전소에서만 실제로 소모) |

기본 생산 공식: `SL/s = 1.0 × (1 + 누적 보너스% / 100) × 근무시간 배수 × 부스트 배수`

---

## 3. 출퇴근 & 근무시간 배수

1. 접속하는 순간이 곧 "출근"이며, 자정(00:00) 이후 언제든 가능
2. 근무 시간대별 SL 생산 배수:
   - **새벽근무** (00:00~06:59:59): **×0.3**
   - **정상근무** (출근 후 9시간 이내): **×1.0**
   - **야근** (9시간 초과 ~ 23:59:59): **×1.5**
3. **퇴근**: 버튼으로 수동 퇴근. 퇴근 후 모든 생산 정지
4. **과로**: 출근 후 **24시간** 내 퇴근하지 않으면 자동으로 "쓰러짐" 상태가 되어 생산이 전면 정지되고, 영구 보너스 **-5%** 페널티. 재접속(재출근)해야 해제됨
5. 근무 배수와 사직서 부스트(2배)는 **곱셈**으로 함께 적용됨 (예: 야근 1.5 × 부스트 2 = 3.0배)

## 6. 업무(성과) 시스템 — 하루(자정) 단위 사이클

### 6-1. 직급별 하루 할당량

| 직급 | 하루 업무 할당량 | 승진심사 필요 여부 |
|---|---|---|
| 인턴~대리 | 0개 (업무 없음) | - |
| 과장 | 1개 | - |
| 차장 | 2개 | - |
| 부장 | 3개 | - |
| 이사 | 4개 | ✅ 필요 |
| 상무 | 5개 | ✅ 필요 |
| 전무 | 6개 | ✅ 필요 |
| 사장 | (해당없음, 최고직급) | - |

### 6-2. 업무 발생 흐름

1. 오전 7시(또는 직전 업무를 놓친 즉시) 새 업무가 그 자리에서 생성(부여)됨
2. 부여 시각(또는 직전 실패 시각)으로부터 **0~3시간 이내 랜덤한 시각**에 "시작 시각"이 정해짐
3. 시작 시각 전에는 완료 버튼 비활성화(⏳ 대기중, 카운트다운 표시)
4. 시작 시각이 되면 업무별 소요시간 동안 완료 가능(✅ 완료 가능, 카운트다운 표시)
5. 소요시간을 넘기면 즉시 만료 → 그 즉시 새 업무 재발생
6. **자정에 그날 업무가 사라지며, 그 순간 할당량 미달 페널티가 확정**됨

### 6-3. 업무 소요시간 가중치 (랜덤 배정)

| 소요시간 | 등장 가중치 |
|---|---|
| 40분 | 70 (가장 흔함) |
| 30분 | 25 |
| 20분 | 3 |
| 15분 | 1.5 |
| 10분 | 0.5 (가장 드묾) |

### 6-4. 업무 종류 (직급별 최소 요구 레벨)

- **과장 이상**부터 등장: 미팅하기, 거래처 만나기/통화하기, 보고서 작성하기, 자료 검토하기 등
- **차장 이상**부터 추가 등장하는 고난도 업무
- **부장 이상**부터 추가 등장하는 임원급 업무 (임원회의 참석, 사업계획 검토 등)
- 총 20종의 업무 풀에서 직급 조건을 만족하는 것 중 랜덤 배정

---

## 7. 업무 페널티

1. 그날 할당량을 다 채우지 못한 상태로 **자정이 지나 업무가 사라지는 순간**, 또는 **퇴근 버튼을 누르는 순간** 페널티 확정
2. 페널티 = **미달 개수 × 5%** (영구 보너스에서 차감, 누적됨)
3. 한 사이클(하루)당 한 번만 적용되며 중복 적용되지 않음
4. **연봉협상과는 완전히 무관** — 협상은 업무 상태를 건드리지 않음

---

## 8. 연봉협상

1. 게이지가 인게임 8시간 동안 차오르며, **100% 다 차야만** 협상 가능(부분 협상 불가)
2. 보너스 = **협상 시점 누적 TL을 1,000 단위로 내림한 값 × 1%** (예: TL 52,850 → +52%)
3. 협상해도 누적 TL은 소모되지 않음(승진·환전에 계속 사용 가능), 게이지만 0으로 리셋
4. 업무 시스템과 완전히 독립적 (7번 항목과 무관)

---

## 9. TL 환전소

- **1 TL = SL 생산 보너스 +0.001%**
- 원하는 만큼 TL을 즉시 SL 보너스로 전환 (1 / 10 / 100 / 전액 프리셋 버튼)
- TL이 실제로 소모되는 유일한 창구

## 10. 사직서 · 아이스아메리카노 · 업무 떠넘기기 (확률형 시스템)

### 10-1. 사직서 (정상근무 시간대 버튼)
- 1시간에 1회 시도 가능 (성공 시엔 부스트 종료 후 1시간부터 재사용 가능)
- **3% 확률 성공** → "한 달만 더 있어주게나" + **10분간 생산량 2배**
- **97% 확률 반려** → 변화 없음

### 10-2. 아이스아메리카노 (새벽근무 시간대, 같은 버튼 슬롯)
- 새벽근무 시간에만 사용 가능, 확률 없이 항상 적용됨
- 그 새벽근무가 끝나는 시각(07:00)까지 배수를 **0.3 → 1.0으로 고정**
- **캘린더 기준 사흘 연속 사용 시** 그 자리에서 **과로로 쓰러짐** (기존 과로 페널티 -5% 적용, 이후 연속 사용일수 리셋)

### 10-3. 업무 떠넘기기 (업무 모달의 도망다니는 버튼)
- 커서를 피해 도망 다니다가(최대 4회 회피 후 잡힘) 클릭되면 판정
- 1시간에 1회 시도 가능 (누른 시점 기준 쿨다운)
- **1% 확률 성공** → 업무 즉시 완료 + **영구 보너스 +5%**
- **0.1% 확률 고발** → **영구 보너스 -10%**
- **98.9% 확률 실패** → "직원이 도망갔습니다" (변화 없음)

## 15. 알려진 이슈 (문서 작성 중 함께 확인된 것)

현재 파일은 **인턴을 0단계로 포함한 11단계 체계**이며, 대부분의 로직(업무 할당량, 승진심사 조건)은 이 체계에 맞게 정확히 계산됩니다. 다만 **이직 가능 조건(`canJobChange`)만 "1단계(사원)부터"로 되어 있어**, 안내 문구("주임부터 이직 가능")와 실제로 1단계 차이가 납니다 — 인턴 단계가 나중에 추가되면서 이 조건만 같이 안 옮겨진 것으로 보입니다. 필요하시면 다음에 바로 맞춰드릴 수 있습니다.
